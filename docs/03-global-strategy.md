# 03. 글로벌 전략

## 1. 왜 글로벌에서 통하는가

- **K-서브컬처 게임의 글로벌 검증**: 블루 아카이브(넥슨게임즈), 승리의 여신: 니케(시프트업)는 일본·북미·동남아에서 매출 상위권을 기록. "캐릭터 수집·육성" 문법은 이미 글로벌 언어다.
- **K-팝 팬덤 문화의 확산**: 포토카드, 응원 문화, 아티스트와의 프라이빗 메시지(버블) 등 팬덤 상호작용 방식이 전 세계 팬층에 익숙하다.
- **미국 빅테크의 공백**: ChatGPT/Claude/Gemini는 생산성·범용성에 집중하며 "재미"와 "캐릭터"를 의도적으로 피한다. Character.AI 등은 반대로 실질 업무 능력이 약하다. 그 사이가 비어 있다.

## 3. 현지화 원칙

1. **i18n은 Day 1부터** — 모든 UI 문자열은 키 기반 (`next-intl`). 하드코딩 금지.
2. **캐릭터 대사는 번역이 아닌 "현지화"** — LLM에게 언어별 페르소나 가이드를 제공하여 각 언어로 자연스러운 말투 생성. (한국어 존댓말/반말 ↔ 영어 캐주얼/포멀 ↔ 일본어 경어체)
3. **시간대 인식** — 데일리 리셋, 알림 시각, 시즌 시작은 사용자 로컬 시간 기준.
4. **문화 감도 검토** — 캐릭터 디자인 노출 수위, 종교·정치 표현, 지역별 기념일 이벤트(설날/추석 vs 추수감사절 vs 오봉).
5. **결제 / 통화** — Stripe 기반 다통화, 지역별 가격 차등(PPP).

## 5. 글로벌 그로스 장치

- **공유 카드 / 에이전트 랩드** — 언어에 덜 의존하는 비주얼 중심 공유물
- **크리에이터 프로그램** — 사용자 제작 캐릭터 페르소나 / 퀘스트 팩 마켓 (P2)
- **IP 콜라보** — 웹툰·게임·버추얼 아이돌 IP와 한정 캐릭터 콜라보
- **커뮤니티 채널** — Discord(글로벌), X, 한국은 카카오 오픈채팅/네이버 카페
