# 01. 컨셉 & 포지셔닝

## 1. 대주제와 해석

| 대주제 | 이 프로젝트에서의 해석 |
| --- | --- |
| **채팅창 다음의 인터페이스** (챗이 아닌 UI/UX, 화면이 없는 제품) | 사용자가 "프롬프트를 쓰고 답을 읽는" 구조에서 벗어난다. 에이전트는 **캐릭터**로, 할 일은 **퀘스트**로, 결과는 **카드/보상**으로 표현한다. 사용자가 화면을 보지 않을 때도 에이전트는 일하고(방치형), 푸시·위젯·음성으로 짧게 보고한다. |
| **한국의 엔터·게임 감각으로 미국 personal agent와 겨루기** | OpenAI/Anthropic/Google은 "도구로서의 비서"를 판다. 우리는 한국이 세계적으로 검증한 **육성·수집·방치·팬덤·시즌 운영** 문법을 에이전트에 입혀 "**계속 돌아오고 싶은 비서**"를 판다. |
| **글로벌** | 처음부터 다국어·다문화를 전제로 설계한다. K-콘텐츠의 정서는 유지하되, 지역별 규제(확률형 아이템, 미성년자 보호)와 문화적 감도를 고려한다. ([03-global-strategy.md](03-global-strategy.md)) |

## 2. 문제 정의

1. **빈 입력창 문제** — 챗 UI는 "무엇을 물어야 할지 아는 사람"에게만 유용하다. 대다수 사용자는 첫 주 이후 이탈한다.
2. **관계가 없다** — 범용 어시스턴트는 매번 같은 톤의 도구다. 애착·성장·기대감이 없어 리텐션 동기가 약하다.
3. **에이전트의 일이 보이지 않는다** — 백그라운드 작업(리서치, 모니터링, 정리)이 끝나도 결과는 텍스트 덩어리일 뿐, 성취감이 없다.
4. **비용 구조** — LLM 호출은 비싸다. 무제한 채팅은 수익 모델과 충돌한다.

## 3. 핵심 가설

> 에이전트를 **"키우는 캐릭터"**로, 작업을 **"퀘스트"**로, 결과를 **"수집 가능한 보상"**으로 바꾸면,
> 같은 LLM 능력으로도 사용 빈도·체류·지불 의향이 크게 오른다.

- 한국 게임 산업은 **육성 + 수집 + 라이브 운영(시즌/이벤트)** 으로 글로벌에서 검증됨 (예: 블루 아카이브, 승리의 여신: 니케, 메이플스토리, 쿠키런)
- K-엔터는 **팬덤 경제**(버블, 포토카드, 응원봉, 버추얼 아이돌 PLAVE 등)로 "관계에 돈을 쓰는" 구조를 증명함
- **방치형 게임**의 "자리를 비운 사이 일이 진행되고, 돌아오면 보상을 수령" 하는 구조는 **비동기 에이전트**와 정확히 겹친다

## 4. 포지셔닝

```
            도구적 (Utility)
                 ▲
   ChatGPT / Claude / Gemini   ← 강력하지만 무미건조
                 │
 혼자 ───────────┼─────────── 관계/재미 (Entertainment)
                 │
   Habitica / Duolingo        Character.AI / Replika
   (게이미피케이션 생산성)       (관계는 있지만 실질 업무 X)
                 │
                 ▼
         ★ sieve: 실제로 일을 해주는 + 키우고 싶은 에이전트
```

**한 줄 정의 (안)**
- KR: "일 잘하는 내 최애를 키우는 에이전트 게임"
- EN: "Your personal agent, raised like a game character — it works while you're away."

## 5. 제품 원칙

1. **챗은 보조 수단이다** — 입력창은 존재하되 메인 화면이 아니다. 메인은 캐릭터 홈, 퀘스트 보드, 수집 도감이다.
2. **실질 가치가 먼저, 재미는 그 위에** — 게임 요소가 실제 업무 품질을 가리면 안 된다. 무작위성(가챠)은 **외형/연출에만**, 핵심 기능에는 절대 적용하지 않는다.
3. **비동기 우선 (Away-first)** — 에이전트가 사용자의 부재 중에 일하고, 돌아왔을 때 "보상 수령" 경험으로 결과를 전달한다.
4. **화면 없이도 작동** — 푸시 알림, 홈 위젯, 음성 브리핑, 이메일 다이제스트만으로도 핵심 루프가 돈다.
5. **건강한 몰입** — 다크 패턴(강제 연속 접속 압박, 과금 유도 확률 조작)을 배제한다. 휴식도 보상한다.

## 6. 컨셉 후보 (택1 또는 결합)

| 안 | 이름(가칭) | 핵심 문법 | 장점 | 리스크 |
| --- | --- | --- | --- | --- |
| A | **에이전트 육성** | 프린세스메이커/다마고치 | 직관적, 캐릭터 애착 | 단일 캐릭터라 확장성 한계 |
| B | **에이전트 파티 (서브컬처형)** | 블루 아카이브/니케 | 리서처·플래너·작가 등 전문 에이전트를 "학생/동료"로 수집·편성. 멀티 에이전트 구조와 자연스럽게 매핑 | 콘텐츠(아트) 제작 비용 |
| C | **방치형 에이전트 사무소** | 방치형 RPG | 화면 없는 제품과 가장 잘 맞음, 저비용 | 관계성 약함 |
| D | **아이돌 매니저** | K-팝 팬덤/육성 | 글로벌 K-팝 팬층에 강한 훅 | 타깃이 좁아질 수 있음 |

**권장: B + C 결합** — "내 에이전트 파티를 편성해 퀘스트를 맡기고, 자리를 비운 사이 일하게 한 뒤, 돌아와 결과와 보상을 수령한다."
멀티 에이전트 아키텍처(역할별 서브에이전트)가 곧 게임의 "캐릭터 수집·편성"이 되므로 기술과 게임 디자인이 한 몸이 된다.

## 7. 핵심 루프

```
 [퀘스트 받기]  ──▶  [파티 편성/위임]  ──▶  [에이전트 작업 (부재 중)]
      ▲                                            │
      │                                            ▼
 [성장/해금]  ◀──  [보상 수령: 결과 카드 + EXP + 재화]  ◀── [푸시: "탐사 완료!"]
```

- **일일 루프**: 아침 브리핑(데일리 퀘스트) → 위임 → 저녁 보상 수령
- **주간 루프**: 주간 리포트 = "주간 보스" 클리어, 랭크 정산
- **시즌 루프(4~8주)**: 시즌 테마, 시즌 패스, 한정 캐릭터 스킨/보이스
