# 02. 게이미피케이션 & 엔터테인먼트 요소

각 요소를 **(1) 게임/엔터 원형 → (2) 에이전트 서비스에 매핑 → (3) 우선순위**로 정리한다.
우선순위: **P0** = MVP 필수, **P1** = 런칭 직후, **P2** = 확장기.

---

## A. 성장 · 육성 (Progression)

| 요소 | 원형 (참고) | 에이전트 서비스 매핑 | 우선순위 |
| --- | --- | --- | --- |
| **에이전트 레벨 & EXP** | RPG 레벨업 | 작업을 완료할수록 에이전트가 레벨업. 레벨 = 실제로 쌓인 **메모리/선호 학습량**을 시각화 ("나를 얼마나 잘 아는가") | P0 |
| **스킬 트리** | 메이플스토리, 디아블로 | 도구(tool) 연결 = 스킬 해금. 예: 캘린더 연동 → "시간술사" 스킬, 웹검색 → "정찰" 스킬. 연동을 게임처럼 유도 | P0 |
| **호감도 / 인연 스토리** | 블루 아카이브 인연 스토리, 미연시 | 함께한 시간·피드백에 따라 호감도 상승 → 캐릭터 전용 에피소드, 말투 변화, 보이스 해금 | P1 |
| **전직 / 각성** | RPG 전직 | 특정 분야 퀘스트를 많이 하면 전문 클래스로 전직 (리서처 → "애널리스트"). 실제로 시스템 프롬프트·도구 세트가 특화됨 | P1 |
| **강화** | 한국 MMORPG 강화 | ⚠️ 확률 강화는 **배제**. 대신 "확정 강화" — 피드백(👍/👎, 수정)을 재료로 결과물 품질 프리셋을 개선 | P2 |
| **사용자 랭크 / 티어** | LoL 티어 (브론즈~챌린저) | "에이전트 지휘관" 랭크. 위임 능력(좋은 지시, 자동화 설정)에 따라 승급 → AI 활용 역량 교육 효과 | P1 |

## B. 수집 (Collection)

| 요소 | 원형 | 매핑 | 우선순위 |
| --- | --- | --- | --- |
| **에이전트 캐릭터 수집** | 서브컬처 가챠 게임 | 역할별 전문 에이전트(리서처, 작가, 플래너, 코치, 번역가…)를 캐릭터로 수집. **기능 캐릭터는 확정 해금**(퀘스트/레벨) | P0 |
| **결과물 카드화** | 포토카드, 트레이딩 카드 | 에이전트가 만든 결과(리서치 요약, 여행 일정, 회의록)를 **등급 있는 카드**로 저장. 등급은 무작위가 아니라 작업 난이도/완성도 기반 | P0 |
| **도감** | 포켓몬 도감 | 수집한 캐릭터·카드·업적 도감. 빈칸이 새 기능 탐색을 유도 (기능 발견성 문제 해결) | P1 |
| **코스튬 / 스킨 / 보이스팩** | 게임 스킨, 아이돌 굿즈 | 캐릭터 외형·보이스·테마 — **주요 BM**. 여기에만 랜덤 뽑기 허용 가능(확률 공개 필수) | P1 |
| **포토카드 꾸미기 (폴꾸)** | K-팝 폴꾸 문화 | 결과 카드를 꾸며 SNS 공유 → 바이럴 루프 | P2 |

## C. 라이브 운영 (Live Ops) — 한국 게임사의 핵심 강점

| 요소 | 원형 | 매핑 | 우선순위 |
| --- | --- | --- | --- |
| **출석 체크** | 한국 모바일 게임 출석부 | 매일 아침 브리핑 확인 = 출석. ⚠️ 연속 끊김 페널티 X, **누적형** 출석으로 압박 완화 | P0 |
| **데일리 / 위클리 퀘스트** | 일일 숙제 | 에이전트가 사용자 상황(캘린더, 목표)을 보고 **개인화된 퀘스트를 생성**. "오늘 운동 30분" "이메일 3개 정리 맡기기" | P0 |
| **시즌 & 시즌 패스** | 배틀패스 | 4~8주 시즌 테마(예: "새해 목표 시즌", "이직 준비 시즌"). 무료/유료 트랙, 보상은 외형·추가 크레딧 | P1 |
| **한정 이벤트** | 콜라보 이벤트 | 연말정산 시즌 이벤트, 수능/시험 시즌, 블랙프라이데이 쇼핑 에이전트 이벤트, IP 콜라보 | P1 |
| **업데이트 패치노트 연출** | 게임 패치노트, 쇼케이스 | 새 모델/기능 출시를 "신규 캐릭터 출시", "대규모 업데이트" 문법으로 연출 | P2 |

## D. 방치형 · 비동기 (Idle / Away) — "화면 없는 제품"의 핵심

| 요소 | 원형 | 매핑 | 우선순위 |
| --- | --- | --- | --- |
| **파견 / 탐사** | 방치형 RPG 파견, 원신 탐사 | 에이전트를 장시간 작업(리서치, 가격 모니터링, 뉴스 트래킹)에 "파견". 진행률 바 표시, 완료 시 푸시 | P0 |
| **오프라인 보상 수령** | 방치형 "접속 보상" | 앱을 열면 부재 중 완료된 결과가 상자처럼 쌓여 있고, 탭해서 연출과 함께 수령 | P0 |
| **자동 전투 / 오토** | 한국 모바일 MMORPG 오토 | 반복 업무 자동화 루틴(매주 월요일 리포트 등) = "오토 사냥" 설정 | P1 |
| **스태미나 / 행동력** | 모바일 게임 스태미나 | **LLM 비용 관리 장치**. 큰 작업은 행동력 소모, 시간 경과로 회복. 무제한 채팅 대비 비용 예측 가능 + 자연스러운 과금 포인트 | P0 |

## E. 소셜 · 팬덤 (Social / Fandom)

| 요소 | 원형 | 매핑 | 우선순위 |
| --- | --- | --- | --- |
| **길드 / 크루** | MMORPG 길드 | 팀·스터디 그룹이 공동 목표(공유 퀘스트)를 진행. B2B/팀 플랜의 진입점 | P2 |

| **친구 에이전트 방문** | 동물의 숲 섬 방문 | 친구의 에이전트 홈 방문, 카드 컬렉션 구경, 응원 보내기 | P2 |
| **버블형 메시지** | 디어유 버블 (아티스트 프라이빗 메시지) | 에이전트가 먼저 말을 건다 — 짧은 안부, 일정 리마인드, 결과 예고. "챗을 먼저 여는 쪽이 에이전트"인 구조 | P0 |
| **공유 가능한 결과 카드** | 스포티파이 랩드, 인스타 스토리 | 주간/연간 "에이전트 랩드" — 바이럴 핵심 장치 | P1 |
| **랭킹 / 리더보드** | 게임 랭킹 | ⚠️ 생산성 비교는 부작용 우려. 친구 간 **협동 지표**(함께 달성한 퀘스트) 중심으로 제한 | P2 |

## G. 화면 없는 접점 (Screenless Touchpoints)

챗/앱 화면을 열지 않아도 핵심 루프가 도는 경로:

| 접점 | 역할 | 구현 (웹 기준) |
| --- | --- | --- |
| 웹 푸시 알림 | "파견 완료!", "오늘의 퀘스트 도착" | PWA + Web Push |
| 홈 화면 위젯 / PWA 아이콘 배지 | 진행률, 미수령 보상 수 | PWA Badging API (위젯은 추후 네이티브) |
| 음성 브리핑 | 출근길 요약 | TTS 오디오 파일 생성 → 링크 |
| 이메일 / 메신저 다이제스트 | 주간 리포트 | 이메일, 추후 Slack/Discord/카카오톡/LINE 봇 |
| 캘린더 이벤트 | 에이전트가 일정에 직접 블록 생성 | Google Calendar 연동 |

## H. 윤리 · 규제 가드레일

| 리스크 | 정책 |
| --- | --- |
| 확률형 아이템 규제 (한국 게임산업법 확률 공개 의무화 2024.3~, 벨기에·네덜란드 등 루트박스 규제) | 랜덤 요소는 **외형 아이템 한정**, 확률 전면 공개, 천장(pity) 제공, 지역별로 랜덤 상품 비활성화 옵션 |
| 중독 / 다크 패턴 | 연속 출석 페널티 금지, 야간 알림 제한, "휴식 보너스"(쉬고 와도 손해 없음) |
| 의존·의인화 | 캐릭터임을 명확히, 정서적 조종 금지, 미성년자 연령 확인 및 보호 모드 |
| 업무 품질 왜곡 | 게임 보상이 결과의 정확성 판단을 흐리지 않도록, 출처·신뢰도 표시는 연출과 분리해 항상 노출 |

## I. MVP 추천 조합 (P0 요약)

1. 에이전트 캐릭터 3종 (리서처 / 플래너 / 작가) — 확정 해금
2. 캐릭터 홈 + 퀘스트 보드 (챗은 보조)
3. 파견(백그라운드 작업) → 푸시 → 보상 수령 연출
4. 결과 카드 & 레벨/EXP
5. 데일리 퀘스트 + 누적 출석
6. 스태미나 기반 사용량 관리
7. 에이전트가 먼저 말 거는 버블형 메시지
